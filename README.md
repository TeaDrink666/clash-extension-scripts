# Clash 扩展脚本

为 Clash Verge Rev 和 FlClash 提供统一代理组及分流规则。

- [CVR 版本](统一代理组扩展脚本-CVR.js)
- [FlClash 版本](统一代理组扩展脚本-FlClash.js)
- [版本说明与设置](版本说明.md)

将对应脚本的完整内容复制到客户端的 JavaScript 扩展脚本编辑器，保存并重新加载配置。

包含手动选择、自动选择、优选自动、故障转移、优选均衡、AI 六个代理组。优选组排除港澳台节点，AI 组手动选择节点。

脚本保留订阅节点与代理集合，替换机场原有代理组及路由规则。国内和局域网直连，其余通过“手动选择”；AI、Bing、Steam 及个人网站另有专用规则，使用前可按需修改。

仓库不包含订阅链接、节点凭据或客户端配置。本地修改后，需要重新复制到客户端才能生效。
